# المرحلة 2: الاستيراد، الأخبار، الخدمات، الإحصاءات، والتوقيع الرقمي

## 1) الاستيراد من Excel أو CSV أو SQL (شاشة «الاستيراد»)
- ثلاثة أنواع: **الطلاب** (`student:register`)، **المقررات** (`course:manage`)، **العلامات** (`grade:manage`).
- القوالب الكاملة في `public/templates/` وتُحمَّل من الشاشة نفسها: `students-template.xlsx` (كل حقول النموذج الفعلي، قوائم منسدلة، ورقة تعليمات)، `courses-template.xlsx`، `grades-template.xlsx`. تُولَّد بـ `tools/make-templates.py` من تعريف النموذج الحي.
- الخطوتان: **فحص** (لا يُكتب شيء، ويُعرض لكل صف خاطئ رقمه وسببه) ثم **اعتماد** (يُحفظ الصحيح ويُبلَّغ عن المرفوض). كل صف يُفحص وحده: خطأ صف لا يُسقط الملف.
- الطلاب: الكلية من القائمة (أو رمزها CSS/CCS…)، يُولَّد الرقم الجامعي بالترميز الجديد، وتُسلَّم كلمات المرور المؤقتة في ملف Excel **مرة واحدة** عند الاعتماد. حتى 1500 طالب في الملف.
- المقررات: المقرر الموجود (نفس الجهة والسنة والفصل والاسم) يُحدَّث ولا يتكرر. العلامات: تُطابق بالاسم أو برمز المقرر، والموجودة تُحدَّث.
- **SQL**: تُقرأ جمل `INSERT INTO … VALUES` (ومعها `CREATE TABLE` لأسماء الأعمدة) فقط، **ولا يُنفَّذ أي SQL**. أسماء الأعمدة عربية أو إنكليزية (`first_name`, `national_id`, `faculty`, …). تواريخ مثل `14/03/2005` وهواتف بلا صفر أول تُصحَّح تلقائياً.
- الحدود: 10 ميغابايت للملف، صيغة `xlsx` (لا `xls` القديمة).

## 2) وسائط الأخبار
- صور (jpg/png/webp/gif ≤ 5MB) وفيديو (mp4/webm ≤ 50MB) برفع مباشر، أو **روابط https**: صورة مباشرة، فيديو مباشر (mp4/webm)، يوتيوب، فيميو (تُعرض مضمَّنة).
- يُتحقق من نوع الملف من بايتاته (لا من امتداده)؛ لا SVG؛ حتى 8 وسائط للخبر. بثّ الفيديو يدعم Range. سياسة الأمان (CSP) وُسِّعت لـ `youtube-nocookie.com` و`player.vimeo.com` وصور https.
- تُخزَّن الملفات في `UPLOAD_DIR/news` (تأكد أنه على القرص الدائم/Volume).

## 3) الخدمات
- حُذفت «طلب تسجيل سنة امتياز» (تُعطَّل بدل الحذف إن كانت عليها طلبات قديمة).
- «طلب حياة جامعية» بلا خيارات. خياراته القديمة في خدمة جديدة **«طلب احتياج»**: نوع الاحتياج (سكن، تغذية، سكن وتغذية، أخرى)، السبب، وتوصيف حر. الطلبات القديمة المنقولة بقيت تحت «طلب احتياج».

## 4) الإحصاءات (شاشة «الإحصاءات»)
- 11 مؤشراً و15 مخططاً (أعمدة، دوائر، خطوط، تكديس) بتحديث تلقائي كل دقيقة، ومرشحات (كلية، سنة قيد)، وتصفية متقاطعة بالنقر على عمود.
- **التصدير**: PDF (نافذة الطباعة ← «حفظ كـ PDF»، بتنسيق A4 أفقي)، **Word** (docx بالمخططات والجداول)، **Excel** (ورقة ملخص + ورقة لكل جدول).

## 5) التوقيع الرقمي لشهادة التسجيل
عند إنشاء حساب أي طالب (يدوياً أو بالاستيراد) تُصدَر في الخلفية **شهادة تسجيل PDF/A-2b** موقَّعة:
- **التوقيع**: CMS/PKCS#7 منفصل (`adbe.pkcs7.detached`)، بصمة **SHA-256**، شهادة **X.509** (RSA-2048)، سمة `signingCertificateV2`.
- **QR** في الشهادة يرتبط بـ `PUBLIC_URL/?verify=SC-XXXX-XXXX`، وبوابة التحقق تعرض النتيجة وتفحص الملف المحفوظ (بصمته وتوقيعه). كما يمكن رفع ملف PDF في البوابة لحساب بصمته على الجهاز ومطابقتها (لا يُرفع الملف).
- **الختم الزمني**: عند ضبط `TSA_URL` يُطلب ختم **RFC 3161** ويُدمج في التوقيع ويُتحقق منه. دونه (أو إن تعثّرت الجهة) يُسجَّل «ختم محلي» بوقت الخادم ولا تفشل الشهادة.
- **تنزيل**: الطالب من «الملف الشخصي»، والموظف من ملف الطالب. للطلاب القدامى: `npm run certs` أو تُصدَر عند أول تنزيل.

### الشهادة «الموثوقة»
الشهادة الموثوقة علناً (التي تعدّها Adobe/Windows موثوقة) **تصدرها جهة اعتماد (CA) بعد توثيق الجهة وتُشترى**، ولا يستطيع الكود إنشاءها. لذلك:
1. اطلب من جهة اعتماد شهادة **توقيع مستندات (Document Signing)** RSA، ثم حوّلها إلى PEM: `openssl pkcs12 -in cert.p12 -nodes -out signing.pem`.
2. ضع محتوى `signing.pem` (مفتاح خاص + الشهادة + السلسلة) في المتغير `SIGNING_PEM` (أو base64 له) على Railway.
3. إلى ذلك الحين تُولَّد **شهادة ذاتية الإصدار** (محفوظة في `data/pki/`): التوقيع والبصمة سليمان وتتحقق منهما البوابة، لكن قارئات PDF تقول «موقِّع غير معروف». البوابة تُنبّه لذلك صراحة.
4. للختم الزمني الموثوق استخدم خادم TSA من نفس الجهة (أو عام مثل `http://timestamp.digicert.com`) في `TSA_URL`.

### ما تحقّقتُ منه وما لم أتحقق منه
- تحقق OpenSSL (`cms -verify`) وPoppler (`pdfsig`: Signature is Valid) و`qpdf --check` من الملف والتوقيع، وختم RFC 3161 فعلي من خادم OpenSSL TSA في الاختبارات.
- بنية **PDF/A-2b** مطبَّقة (خطوط مضمَّنة، XMP، OutputIntent sRGB، بلا تشفير/جافاسكربت) لكنها **لم تُفحص بمدقق PDF/A رسمي** (veraPDF غير متاح عندي). شغّل veraPDF على ملف عيّنة قبل الاعتماد الرسمي.
- النصوص العربية في الشهادة بخط **DejaVu Sans** المضمَّن (حر ويُسمح بتضمينه).

## ملاحظة عن الخط AL Mohanad
الخط المرفق (`public/fonts/`) **لا يحوي حروف عربية بترميز Unicode** (يستخدم ترميزاً قديماً)، فلا يستطيع المتصفح ولا ملفات PDF عرض نص عربي به؛ لذلك أُزيل ربطه من `style.css` ويستخدم الموقع الخط النظامي (Cairo/Tajawal/…). إن توفرت نسخة Unicode من الخط ضعها في `public/fonts/` وأضف `@font-face` في أول `style.css`.

## 6) الحذف والتعديل لكل البيانات
| البيانات | تعديل | حذف | الصلاحية |
|---|---|---|---|
| المقررات | ✓ (يُزامن نسخة العلامات) | ✓ إن لم تكن لها علامات | `course:manage` |
| العلامات | ✓ (إعادة الإدخال لنفس المقرر والعام) | ✓ | `grade:manage` |
| الأخبار | ✓ (العنوان والنص والتثبيت) | ✓ | `news:manage` |
| الشكاوى | الرد | ✓ | `complaint:manage` |
| الكليات والمعاهد | ✓ (الرمز لا يتغير إن كان فيها طلاب) | ✓ إن لم يكن فيها طلاب أو مقررات | `program:manage` |
| البرامج | ✓ (المدة لا تقل عن أعلى سنة مستخدمة) | ✓ إن لم يكن فيها طلاب أو مقررات | `program:manage` |
| الطلاب | ✓ | ✓ إن لم يكن لهم طلبات | `student:update` / **`student:delete`** (جديدة، للمدير) |
| الذمم | ✓ | ✓ | `holds:manage` |
| قواعد الفحص | ✓ (الرسالة والمعاملات مع تحقق) | ✓ | `rules:manage` |
| الحسابات الإدارية | ✓ | ✓ (لا النفس ولا آخر مدير ولا حساب مرتبط بسجلات) | `user:manage` |
| الوحدات الإدارية | ✓ | ✓ (روابطها تُحذف معها) | `role:manage` |

**ما لا يُحذف عمداً:** سجل التدقيق والطلبات وأحداثها والوثائق الموقَّعة، لأن مشغّلات قاعدة البيانات (001_init.sql) تمنع تعديلها أو حذفها ضماناً للإثبات. لذلك لا يُحذف طالب قدّم طلبات (يُغيَّر وضع قيده)، ولا خدمة قُدِّم عليها طلب. كل تعديل أو حذف يُسجَّل في سجل التدقيق.

## 7) صفحة التصدير والهوية البصرية والعرض المتكيّف
- **التصدير** (تبويب «التصدير»، صلاحية `data:export` للموظف والمدير): الطلاب بسجلاتهم الكاملة، المواد، العلامات، الطلبات، الذمم، الشكاوى، أو الكل معاً. المرشحات: الكلية، البرنامج، السنة الدراسية، الفصل، العام الدراسي، حالة القيد، سنة القيد. الصيغ: Excel (مع خيار ورقة لكل سنة وفصل للعلامات)، CSV (ملف zip عند «الكل»)، JSON، Word، PDF (نافذة الطباعة). ملفات CSV/Excel تُحيِّد الخلايا التي تبدأ بـ `= + - @`، وكل تصدير يُسجَّل في سجل التدقيق.
- **الأيقونات**: مجموعة موحّدة في `public/icons.js` (خط بلون الهوية الأخضر مع لمسة ذهبية)، تُستعمل في كل الواجهات عبر `UA.icon(name, size)`.
- **العرض**: يُحدَّد بعرض الشاشة لا بدور المستخدم (الحد 820px). الحاسوب: ترويسة وتبويبات وبطاقات متعددة الأعمدة؛ الجوال: واجهة التطبيق بالشريط السفلي. يتبدّل العرض فوراً عند تغيير حجم النافذة أو تدوير الجهاز.
