# المواد والعلامات (إعادة التنظيم)

## دليل المواد
- جدول واحد بكل مقررات الكليات والمعاهد: الجهة، البرنامج، السنة، الفصل، المقرر، الرمز، الساعات، المدرّس، عدد العلامات، الحالة.
- **فلترة**: بحث حي (اسم المقرر/الرمز/المدرّس/الجهة) + كلية/معهد، برنامج، سنة، فصل، حالة. **ترتيب**: بالنقر على أي عنوان عمود (تصاعدي/تنازلي). صفحات 25/50/100.
- **＋ إضافة مقرر**: زر يفتح نافذة (الكلية ← البرنامج ← السنة والفصل ← الاسم والساعات والرمز والمدرّس). السنوات المتاحة تتبع مدة البرنامج.
- لكل صف: **تعديل** (نفس النافذة)، **تعطيل/تفعيل**، **حذف** (يُرفض إن كانت للمقرر علامات؛ يُنصح بتعطيله).

## جدول العلامات (بدل «إدخال العلامات»)
- جدول كامل: الرقم الجامعي، الطالب، الكلية/المعهد، المقرر ورمزه، السنة/الفصل، العام الدراسي، النظري، العملي، المجموع، النتيجة، ومعه ملخص (عدد العلامات، الطلاب، المتوسط، نسبة النجاح) يتبع الفلاتر.
- **البحث** (من الخادم، حي): اسم الطالب، الرقم الجامعي، الكلية/المعهد/البرنامج، اسم المقرر أو رمزه. مرشحات: كلية/معهد، سنة، فصل، عام دراسي، ناجح/راسب. ترتيب بالنقر على العنوان، وصفحات حتى 100 صف.
- **＋ إدخال علامات جديدة**: نافذة: ابحث عن الطالب ← اختر ← اختر المقرر والعام والعلامتين ← حفظ. تبقى النافذة مفتوحة لإدخال مقرر آخر لنفس الطالب (زر «تغيير الطالب» أو «إنهاء»).
- **تعديل/حذف** من الجدول مباشرة. تعديل علامة = إعادة إدخالها لنفس المقرر والعام.

واجهة برمجية جديدة: `GET /api/grades?q=&faculty=&course=&level=&semester=&year=&status=&sort=&dir=&page=&size=` (صلاحية `grade:manage` أو `student:read`). و`GET /api/courses` للموظف يعيد كل المقررات مع الجهة والبرنامج وعدد العلامات.
